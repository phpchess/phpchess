| B23 | **Board flicker during live play**: in the C3-1 5+3 test the game page flickered (4.x did not). Likely causes: the page reloads itself when offers or the pace change (window.location.reload in game-page.js), and updateMoveInput() removes and redraws all board markers on every news. Solution approach: (1) no reloads during a running game: the server renders the offer area (draw, pace, rematch, abort) as a template part and GET /games/{id}/offers returns it; the script swaps only that element when the state's offer fields change; the game end updates the status line and buttons the same way. (2) markers: keep a small record of the markers shown (legal targets, premove, last move) and add/remove only the difference, never removeMarkers() on a poll. (3) board: setPosition only when the ply changed, without animation for our own move already shown. (4) clocks: update textContent only when the shown text changes. (5) test: a script check that a poll with news but no move does not touch the board or reload. | 2026-11-24 | Found in the C3-1 local test. |
